# MBTI 職業匹配平台

這是一個基於 MBTI（邁爾斯-布里格斯類型指標）的職業匹配平台。該平台旨在幫助用戶了解自己的 MBTI 人格類型，並根據這些信息推薦適合的職業選擇。

## 1. 項目概述

本平台旨在通過MBTI性格測試來幫助用戶找到最適合自己的工作，提供薪資範圍、公司評價、股價歷史和透明度等信息，並根據不同MBTI類型提供職業發展建議。

## 2. 目標和目標用戶

**目標**：
- 幫助求職者找到適合自己的工作
- 提高公司招聘透明度
- 提供個性化的職業發展建議

**目標用戶**：
- 求職者
- 職業發展顧問
- 公司人力資源部門

## 4. 技術規劃

**前端**：
- 框架：React
- 樣式：Tailwind CSS
- 狀態管理：Redux
- 圖表庫：Chart.js

**後端**：
- 語言：Python, Node.js
- 框架：Flask（Python）或 Express.js（Node.js）
- API層：Apollo GraphQL
- 中介軟件：Apollo Server

**數據庫**：
- SQL：PostgreSQL
- NoSQL：MongoDB

**雲服務**：
- 平台：Cloudflare
- 服務：AWS（Lambda, DynamoDB, S3, EC2）

**第三方API**：
- MBTI測試API
- 職位信息API（如LinkedIn, Glassdoor）
- 股票數據API（如Alpha Vantage）

## 開始使用

1. 克隆此倉庫
2. 安裝依賴：
   ```
   npm install
   ```
3. 啟動開發服務器：
   ```
   npm start
   ```
4. 在瀏覽器中打開 http://localhost:3000

## 可用腳本

在項目目錄中，您可以運行：

- `npm start`：在開發模式下運行應用
- `npm test`：啟動測試運行程序
- `npm run build`：為生產環境構建應用
- `npm run eject`：單向操作，自定義構建工具和配置選擇
